# 食譜

## 格式說明

| 欄位     | 說明                             |
| -------- | -------------------------------- |
| 份量     | 一次做出幾杯                     |
| 用量     | 材料表的量，是整鍋的量           |
| 總成本   | 各材料用量的成本合計，不含耗材   |
| 每份成本 | 總成本 ÷ 份量                    |
| 售價     | 建議零售價，單杯                 |
| 毛利     | 售價 − 每份成本                  |
| 毛利率   | （售價 − 每份成本）÷ 售價 × 100% |

定價一律以每份為基準；總成本是整鍋的量，不可直接與售價相減。

## 烘焙甜點

### 奶酪

**類別：** 甜點  
**份量：** 4 杯

#### 材料

| 材料   | 用量       | 小計 |
| ------ | ---------- | ---- |
| 吉利丁 | 3 片（6g） | 9元  |
| 牛奶   | 300ml      | 27元 |
| 鮮奶油 | 100ml      | 39元 |
| 糖     | 8g         | <1元 |
| 鹽     | 0.8g       | <1元 |
| 香草精 | 2ml        | 2元  |

**總成本：** 77 元（每份 19.26 元）

#### 步驟

1. 吉利丁片泡冷水軟化，約 5 分鐘。
2. 牛奶、鮮奶油、糖、鹽倒入鍋中，小火加熱至糖融化（勿沸騰）。
3. 離火後加入香草精攪拌均勻。
4. 擠乾吉利丁，加入熱液體中攪拌至完全融化。
5. 過篩後倒入模具，放涼後冷藏至少 4 小時。

#### 定價

**售價：** 60 元（毛利 40.74 元，毛利率 67.9%）

### 抹茶奶酪

**類別：** 甜點  
**份量：** 4 杯

#### 材料

| 材料   | 用量       | 小計 |
| ------ | ---------- | ---- |
| 吉利丁 | 3 片（6g） | 9元  |
| 牛奶   | 300ml      | 27元 |
| 鮮奶油 | 100ml      | 39元 |
| 抹茶粉 | 4g         | 38元 |
| 糖     | 8g         | <1元 |
| 鹽     | 0.8g       | <1元 |
| 香草精 | 2ml        | 2元  |

**總成本：** 115 元（每份 28.76 元）

#### 步驟

1. 吉利丁片泡冷水軟化，約 5 分鐘。
2. 牛奶、鮮奶油、糖、鹽倒入鍋中，小火加熱至糖融化（勿沸騰）。
3. 抹茶粉不另外加水調開，直接取少量熱牛奶液沖開拌勻，再倒回鍋中。
4. 離火後加入香草精攪拌均勻。
5. 擠乾吉利丁，加入熱液體中攪拌至完全融化。
6. 過篩後倒入模具，放涼後冷藏至少 4 小時。

#### 定價

**售價：** 90 元（毛利 61.24 元，毛利率 68.0%）

#### 備註

- 抹茶粉小計依 100g 包裝（950元）計；改用 500g 包裝為 30元，總成本 107 元（每份 26.86 元）。
