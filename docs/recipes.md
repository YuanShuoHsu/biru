## 烘焙甜點

### 奶酪

**類別：** 甜點  
**份量：** 3 份

#### 材料

| 材料   | 份量  | 小計 |
| ------ | ----- | ---- |
| 吉利丁 | 2 片  | 6元  |
| 牛奶   | 240ml | 21元 |
| 鮮奶油 | 60ml  | 24元 |
| 糖     | 6g    | <1元 |
| 鹽     | 0.5g  | <1元 |
| 香草精 | 3ml   | 3元  |

**總成本：** 55 元

#### 步驟

1. 吉利丁片泡冷水軟化，約 5 分鐘。
2. 牛奶、鮮奶油、糖、鹽倒入鍋中，小火加熱至糖融化（勿沸騰）。
3. 離火後加入香草精攪拌均勻。
4. 擠乾吉利丁，加入熱液體中攪拌至完全融化。
5. 過篩後倒入模具，放涼後冷藏至少 4 小時。
