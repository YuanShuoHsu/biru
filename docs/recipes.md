## 烘焙甜點

### 奶酪

**類別：** 甜點  
**份量：** 4 杯

#### 材料

| 材料   | 份量       | 小計 |
| ------ | ---------- | ---- |
| 吉利丁 | 3 片（6g） | 9元  |
| 牛奶   | 300ml      | 27元 |
| 鮮奶油 | 100ml      | 39元 |
| 糖     | 8g         | <1元 |
| 鹽     | 0.8g       | <1元 |
| 香草精 | 2ml        | 2元  |

**總成本：** 77 元

#### 步驟

1. 吉利丁片泡冷水軟化，約 5 分鐘。
2. 牛奶、鮮奶油、糖、鹽倒入鍋中，小火加熱至糖融化（勿沸騰）。
3. 離火後加入香草精攪拌均勻。
4. 擠乾吉利丁，加入熱液體中攪拌至完全融化。
5. 過篩後倒入模具，放涼後冷藏至少 4 小時。

#### 定價

| 售價 | 成本 | 毛利 | 毛利率 |
| ---- | ---- | ---- | ------ |
|      | 77元 |      |        |

### 抹茶奶酪

**類別：** 甜點  
**份量：** 4 杯

#### 材料

| 材料   | 份量       | 小計 |
| ------ | ---------- | ---- |
| 吉利丁 | 3 片（6g） | 9元  |
| 牛奶   | 300ml      | 27元 |
| 鮮奶油 | 100ml      | 39元 |
| 抹茶粉 | 4g         | 38元 |
| 糖     | 8g         | <1元 |
| 鹽     | 0.8g       | <1元 |
| 香草精 | 2ml        | 2元  |

**總成本：** 115 元

#### 步驟

1. 吉利丁片泡冷水軟化，約 5 分鐘。
2. 牛奶、鮮奶油、糖、鹽倒入鍋中，小火加熱至糖融化（勿沸騰）。
3. 抹茶粉不另外加水調開，直接取少量熱牛奶液沖開拌勻，再倒回鍋中。
4. 離火後加入香草精攪拌均勻。
5. 擠乾吉利丁，加入熱液體中攪拌至完全融化。
6. 過篩後倒入模具，放涼後冷藏至少 4 小時。

#### 定價

| 售價 | 成本  | 毛利 | 毛利率 |
| ---- | ----- | ---- | ------ |
|      | 115元 |      |        |

#### 備註

- 抹茶粉小計依 100g 包裝（950元）計；改用 500g 包裝為 30元，總成本 107 元。
